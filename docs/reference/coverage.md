# Coverage

Every service is tested with the official SDK for its cloud. Terraform (hashicorp/aws 6.x, google and azurerm) and the CDK CLI run against pogi in
[`scripts/conformance.sh`](../../scripts/conformance.sh).

Depth:

- **Deep:** real behavior, plus wiring to other services.
- **Core:** the main API, with real semantics.
- **Thin:** create, describe and delete. That is enough for infrastructure tools such as Terraform.

ARNs use the right prefix for the region (`aws`, `aws-cn` for China, `aws-us-gov` for GovCloud). The Terraform run also passes
with `REGION=us-gov-west-1` and `REGION=cn-north-1`.

Names that end in `.localhost` (virtual-host S3, `execute-api`, `lambda-url`) resolve on macOS and on most Linux systems. They don't resolve in
Alpine Linux containers, which use a small C library without that rule. `pogi doctor` tells you which case you are in.

pogi registers 181 services: 131 AWS, 26 Google Cloud and 24 Azure. Each service name is followed by its registry id, the name `pogi services` prints.
